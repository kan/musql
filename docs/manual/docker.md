# Docker 連携

ローカルで動いている **Docker コンテナの MySQL と Redis** を自動検出して接続できます。接続情報を手で調べる必要はありません。

## 使い方

![Docker コンテナ一覧モーダル](img/docker-list.png)
<!-- 撮影: メイン画面で Docker ボタンを押した状態。検出された MySQL コンテナが一覧表示され、資格情報入力（user / password / SSL モード）のモーダルが見えると良い。 -->

1. メイン画面の **Docker ボタン** を押す
2. 検出されたコンテナの一覧から選ぶ（名前の下に、種類とイメージが出ます）
3. **ユーザー / パスワード / SSL モード** を入力して接続する

MySQL のコンテナはクエリ画面で、Redis のコンテナは [Redis の画面](redis.md) で開きます。

資格情報はコンテナごとに記憶されます（ユーザーと SSL モードはローカル設定、パスワードは資格情報マネージャー）。最後に使った設定は、同じ種類の新しいコンテナにも初期値として適用されます。ただし Redis のパスワードは引き継ぎません（パスワードの無いサーバーにパスワードを送ると、接続に失敗するため）。

入力の初期値は種類ごとに違います。

| 種類 | ユーザー | SSL モード |
|------|----------|------------|
| MySQL | `root` | `REQUIRED` |
| Redis | 空（既定のユーザー `default`） | `DISABLED` |

MySQL の `REQUIRED` は証明書を検証しないので、コンテナが自動生成した自己署名の証明書でも接続できます。SSL を有効にしていないサーバーには、`DISABLED` を選んで接続してください。Redis の公式イメージは TLS とパスワードを使わずに動くので、パスワード欄を空のまま接続できます。パスワード（`requirepass`）を設定したコンテナには、パスワードを入力してください。

> **接続方法**：Docker への接続は、名前付きパイプ → TCP（`127.0.0.1:2375` / `2376`）の順にフォールバックします。WSL2 上の dockerd にも対応します。

## 検出の条件

起動中（running）のコンテナのうち、次の条件で MySQL か Redis のコンテナを検出します。

- **`musql.engine` ラベル**があれば、その種類として検出します（`mysql` / `mariadb` / `redis`）。この版の知らない値なら一覧には出しますが、接続はできません
- ラベルが無ければ、**3306 番**（`musql.port` があればその番号）を公開しているか、**`musql.enable=true`** ラベルが付いていれば MySQL として検出します
- そのどちらでもなく、**6379 番**を公開していれば Redis として検出します

Redis を 6379 番以外のポートで動かしているコンテナには、`musql.engine=redis` と `musql.port` の両方を付けてください。`musql.engine` が無いと、`musql.port` は MySQL のポートとして扱います。

## ポート未公開コンテナへの接続

ホストにポートをバインドしていないコンテナには、muSQL が一時的な **`alpine/socat` トンネルコンテナ**を作成して TCP 接続します。トンネルコンテナは `auto_remove: true`、`musql.tunnel=true` ラベル付きで、一覧には表示されません。

トンネルは、アプリ起動時、終了時、クエリ画面か Redis の画面を閉じたときに自動でクリーンアップされます。

## `musql.*` ラベルでのカスタマイズ

コンテナに次のラベルを付けると、検出時の初期値をカスタマイズできます。

| ラベル | 意味 |
|--------|------|
| `musql.engine` | 種類（`mysql` / `mariadb` / `redis`）。ポートを公開していなくても検出対象になる |
| `musql.enable=true` | 3306 を公開していなくても MySQL として検出対象にする |
| `musql.name` | 一覧に表示する名前 |
| `musql.user` | 既定のユーザー |
| `musql.password` | 既定のパスワード |
| `musql.port` | ポート（無ければ 3306 か 6379）。`musql.engine` が無いときは MySQL のポート |
| `musql.ssl-mode` | 既定の SSL モード（`DISABLED` または `REQUIRED`。それ以外の値は無視） |

ラベルの値は、記憶済みの設定より優先されます。MySQL は `musql.user` と `musql.password` の両方、Redis は `musql.password` を付けたコンテナで、入力のモーダルを出さずに接続します。このとき SSL モードは `musql.ssl-mode` の値になり、ラベルが無ければ上の表の初期値です。
