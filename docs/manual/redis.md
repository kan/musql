# Redis

muSQL は MySQL に加えて **Redis** にも接続できます。キーの一覧から値を確かめ、CLI タブでコマンドを実行できます。

## 接続を作る

接続プロファイルの編集画面で、**DBエンジン** に `Redis` を選びます。既定のポートは 6379 に変わります。

| 項目 | Redis での意味 |
|------|----------------|
| ホスト / ポート | Redis サーバーのアドレスとポート（既定 6379） |
| DB 番号 | 使うデータベースの番号（空なら 0） |
| ユーザー | ACL のユーザー名。空なら既定のユーザー（`default`）で認証します |
| パスワード | `requirepass` または ACL のパスワード。認証のないサーバーでは空のままにします |
| SSL モード | `DISABLED`：TLS を使いません。`REQUIRED`：TLS で暗号化し、証明書は検証しません。`VERIFY_CA`：証明書を検証し、ホスト名は検証しません。`VERIFY_IDENTITY`：証明書とホスト名を検証します |

CA 証明書を指定すると、Windows の信頼済み証明書の代わりにその証明書で検証します。SSH 踏み台とパスワードの保存方針は MySQL と同じです。→ [SSH 踏み台接続](ssh.md)、[接続プロファイル](connections.md#パスワードの保存方針)

接続テストは、サーバーに `PING` を送って応答を確かめます。

## 画面構成

Redis のプロファイルを開くと、Redis 用の画面が開きます。左にキーの一覧、右にタブが並びます。1 つの muSQL で開ける接続は 1 つなので、クエリ画面が開いていれば閉じます。

- **CLI タブ**：コマンドを入力して実行するタブです。常に先頭にあり、閉じられません。
- **キーのタブ**：一覧でキーをクリックすると開きます。キーごとに 1 枚です。

左上には、接続先の Redis のバージョンと DB 番号が出ます。ここを押すと DB の一覧（DB ごとのキーの数つき）が開き、選んだ DB に切り替わります。切り替えると、キーの一覧は切り替え先の DB に変わり、開いていたキーのタブは閉じます。

## キーの一覧

キーは `SCAN` で読みます。一度に約 200 件を表示し、続きは **さらに読み込む** で読みます。サーバーをブロックする `KEYS` は使いません。

- **絞り込み**：上の欄に入力すると、入力に合うキーだけを表示します（入力を止めると読み直します）。`sample` のように書くと、キー名に `sample` を含むキーを探します。`*`、`?`、`[` を含めると、`user:*` のような Redis のパターンとして扱います。空なら全キーです。
- **型ごとのグループ**：キーは型（`string` / `hash` / `list` / `set` / `zset` / `stream` など）ごとにまとめて、名前の順に並べます。グループの見出しを押すと、折りたためます。見出しの件数は読み込んだ分の数で、続きが残っていれば `+` が付きます。`SCAN` はキーを順不同で返すので、続きを読むと各グループに追加されます。
- **再読み込み**：右上のボタンで、一覧を読み直します。

## キーのタブ

上の行に、型、TTL、メモリ使用量、件数（文字列なら長さ）が出ます。TTL は残りの秒数と期限の日時で表し、期限が無ければ「期限なし」と出ます。右端のボタンで読み直せます。

- **コピー**：文字列の値は、右上の **コピー** でクリップボードにコピーできます（表示している先頭の 1 MiB まで）。
- **ファイル出力**：表で出る型は、右上の **ファイル出力** から CSV か TSV で保存、またはクリップボードへコピーできます。クエリ画面の「現在の表示」と同じで、文字コードと改行コードも選べます。→ [エクスポート](export.md)

値は型ごとに表示します。

| 型 | 表示 |
|----|------|
| string | 値をそのまま表示します。JSON なら整形して表示します |
| hash | field と value の表 |
| list | index と value の表 |
| set | member の表 |
| zset | score と member の表（score の小さい順） |
| stream | id と fields の表（fields は JSON） |

表はクエリ画面の結果と同じく、ページ送り、列見出しでの並べ替え、行のクリックでの詳細表示ができます。上の表にない型（RedisJSON など）は、型と TTL だけを表示します。値は CLI タブで確かめてください。

## CLI タブ

redis-cli と同じように、1 行に 1 つのコマンドを入力して Enter で実行します。応答も redis-cli と同じ形（`(integer) 1`、`(nil)`、番号付きの配列など）で表示します。

- **補完**：コマンド名を入力し始めると、合うコマンドの候補が入力欄の上に出ます。Tab で先頭の候補を入力し、↑ / ↓ で候補を選んで Enter でも入力できます。
- **ヘルプ**：入力欄の下に、入力中のコマンドの書式と説明が出ます。何も入力していないときは、型ごとの主なコマンドが並び、押すとそのコマンドが入力欄に入ります。書式と説明はサーバーから取得します（英語）。Redis 7 より前のサーバーでは、補完と書式は出ません。
- **引用符**：空白を含む値は `"..."` か `'...'` で囲みます。`"..."` の中では `\n` や `\"` などのエスケープが使えます。`\xHH` は 1 バイトを表します（redis-cli と同じ）。
- **履歴**：候補が出ていないときの ↑ / ↓ で、これまでに実行したコマンドをたどれます。履歴はプロファイルごとに 100 件まで残ります。パスワードを含みうるコマンド（`AUTH`、`ACL`、`HELLO`、`MIGRATE` と、`requirepass` や `masterauth` を含む行）は履歴に残しません。
- **DB の切り替え**：`SELECT 2` のように DB を切り替えると、キーの一覧も切り替え先の DB に変わります。開いていたキーのタブは閉じます。
- **AI アシスト**：入力欄の右の **AI アシスト** で、やりたいことからコマンドを作れます。作ったコマンドは入力欄に入るだけで、Enter を押すまで実行しません。→ [AI アシスト](ai-assist.md#redis)

次のコマンドは、サーバー全体に作用する（または実行中にサーバーを止める）ため、実行前に確認します。

- `FLUSHALL`、`FLUSHDB`、`SHUTDOWN`、`DEBUG`、`SWAPDB`、`KEYS`、`SAVE`、`REPLICAOF`、`SLAVEOF`、`FAILOVER`
- `CONFIG SET` / `REWRITE` / `RESETSTAT`、`SCRIPT FLUSH`、`FUNCTION FLUSH` / `DELETE` / `RESTORE`、`CLUSTER RESET` / `FAILOVER` / `FORGET`、`CLIENT PAUSE` / `KILL`、`ACL SETUSER` / `DELUSER`

次のコマンドは実行できません。

- `SUBSCRIBE`、`PSUBSCRIBE`、`SSUBSCRIBE`、`MONITOR` など、接続をメッセージの待ち受けに切り替えるコマンド
- `MULTI`、`WATCH`、`RESET`、`HELLO`、`AUTH`、`QUIT`、`CLIENT REPLY` など、接続の状態を変えるコマンド。CLI タブはキーの一覧やキーのタブと同じ接続を使うので、実行すると一覧とキーのタブが動かなくなります

## 制限

- 1 つのキーで表示するのは、先頭の 500 件までです（文字列は先頭の 1 MiB まで）。超えた分は CLI タブで確かめてください。
- キー名と値は UTF-8 の文字列として表示します。UTF-8 として読めないバイトや制御文字を含むもの（バイナリ）は、redis-cli と同じ表記で表示します。読めないバイトと制御文字は `\xHH`、改行は `\n`、`\` は `\\`、`"` は `\"` になります。日本語などの読める文字は、そのまま表示します。キー名は改行やタブを含むときもこの表記になります。
- バイナリのキーも一覧から開けます。CLI では `"..."` の中にその表記のまま書けば指定できます。
- バイナリの文字列の値には、その旨の注記が付きます。コピーされるのは表示どおりの表記です。
- 応答に 8 秒以上かかるコマンドは失敗します。次の操作で接続をやり直し、`SELECT` で切り替えた DB も選び直します。`BLPOP` のように待ち続けるコマンドも、8 秒で打ち切られます。
