## テーマと言語

各ウィンドウのハンバーガーメニュー（≡）の **View / 表示** から切り替えます。

- **テーマ**：ライト / ダーク。
- **言語**：日本語 / English。

設定はウィンドウ間で共有され、次回起動時にも保持されます。

## アップデート

- **Microsoft Store 版**：Store 経由で自動更新されます。
- **GitHub Releases 版**：起動の少し後に自動でアップデートを確認し、ヘルプメニューから手動確認もできます（Ed25519 署名付き）。

## マニュアルの表示

このマニュアルはアプリ内でも読めます。次のいずれかで開きます。

- `F1` キー（全ウィンドウ）
- メイン画面のハンバーガーメニュー（≡）→ **ヘルプ → マニュアル**
- 各画面にある **?** ボタン（該当ページへ直接ジャンプ）

表示には GitHub から本文を取得するためネットワーク接続が必要です。オフライン時はビューアの「GitHub で開く」からブラウザ表示を試せます。

## キーボードショートカット

| 操作 | ショートカット | 画面 |
|------|----------------|------|
| マニュアルを開く | `F1` | 全画面 |
| 新規プロファイル | `Ctrl+N` | メイン |
| 新規グループ | `Ctrl+Shift+N` | メイン |
| QuickOpen（コマンドパレット） | `Ctrl+P` | クエリ |
| 新規 SQL タブ | `Ctrl+T` | クエリ |
| この行を実行 | `Ctrl+Enter` | クエリ（SQL タブ） |
| すべて実行 | `Ctrl+Shift+Enter` | クエリ（SQL タブ） |
| SQL を整形 | `Ctrl+Shift+F` | クエリ（SQL タブ） |
| ウィンドウ / タブを閉じる | `Ctrl+W` | クエリ |

> **無効化されているキー**：`Ctrl+R` / `F5`（リロード）と `Ctrl+P` の印刷ダイアログは、誤操作を防ぐため無効化されています（`Ctrl+P` は QuickOpen に割り当て）。
