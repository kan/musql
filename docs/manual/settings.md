## テーマと言語

各ウィンドウのハンバーガーメニュー（≡）の **View / 表示** から切り替えます。

- **テーマ**：ライト / ダーク。
- **言語**：日本語 / English。

設定はウィンドウ間で共有され、次回起動時にも保持されます。

## ウィンドウの位置

メイン画面とクエリ画面は、閉じたときのサイズと位置を覚えていて、次に開いたときに同じ場所へ戻ります。

muSQL は、最後に閉じたときの仮想デスクトップも覚えています。次に起動すると、メイン画面がそのデスクトップに開き、表示もそこへ切り替わります。覚えていたデスクトップが削除されていた場合は、表示中のデスクトップに開きます。

muSQL をすでに起動している状態でもう 1 つ起動した場合、2 つ目以降は表示中のデスクトップに開きます。

## アップデート

- **Microsoft Store 版**：Store 経由で自動更新されます。
- **GitHub Releases 版**：起動の少し後と、その後は 1 時間ごとに、自動でアップデートを確認します。開いたままにしていても、新しい版が出るとメイン画面に知らせが出ます。ヘルプメニューから手動確認もできます（Ed25519 署名付き）。

## マニュアルの表示

このマニュアルはアプリ内でも読めます。次のいずれかで開きます。

- `F1` キー（全ウィンドウ）
- メイン画面のハンバーガーメニュー（≡）→ **ヘルプ → マニュアル**
- 各画面にある **?** ボタン（該当ページへ直接ジャンプ）

表示には GitHub から本文を取得するためネットワーク接続が必要です。オフライン時はビューアの「GitHub で開く」からブラウザ表示を試せます。

## ログ

muSQL は、接続の失敗や内部エラーをログファイルに記録します。不具合を報告するときの手がかりになります。

- **開き方**：メイン画面のハンバーガーメニュー（≡）→ **ヘルプ → ログフォルダを開く**
- **場所**：GitHub Releases 版は `%LOCALAPPDATA%\jp.co.communitylinks.musql\logs\muSQL.log`。Microsoft Store 版は、Windows がアプリ専用の領域へ保存先を振り替えるため、`%LOCALAPPDATA%\Packages\` の下の muSQL のフォルダになります。どちらの版でも、上のメニューから開くのが確実です
- **大きさ**：1 ファイルは約 1MB までで、古いものは 2 世代まで残ります

記録するのは、接続や接続テストの失敗、同期ファイルの読み書きの失敗、アップデート確認の失敗、AI アシストや 1Password の呼び出しの失敗、画面側の予期しないエラーです。接続の失敗には、接続先のホスト名とユーザー名が含まれます。

パスワード、API キー、SQL の本文、クエリの結果は記録しません。クエリの実行エラーも記録しません（エラー文に SQL の一部が入るため）。

ログは手元のファイルに書くだけで、外部には送信しません。共有するときは、中身を確認してからにしてください。

## バージョンとライセンス

メイン画面のハンバーガーメニュー（≡）→ **ヘルプ → muSQL について** で、現在のバージョンと、muSQL が利用しているオープンソースソフトウェアの一覧を確認できます。

一覧の項目を選ぶと、そのソフトウェアのライセンスの本文を表示します。上の入力欄で、名前やライセンス名による絞り込みができます。

## キーボードショートカット

| 操作 | ショートカット | 画面 |
|------|----------------|------|
| マニュアルを開く | `F1` | 全画面 |
| 新規プロファイル | `Ctrl+N` | メイン |
| 新規グループ | `Ctrl+Shift+N` | メイン |
| QuickOpen（コマンドパレット） | `Ctrl+P` | クエリ |
| 新規 SQL タブ | `Ctrl+T` | クエリ |
| この行を実行 | `Ctrl+Enter` | クエリ（SQL タブ） |
| すべて実行 | `Ctrl+Shift+Enter` | クエリ（SQL タブ） |
| SQL を整形 | `Ctrl+Shift+F` | クエリ（SQL タブ） |
| ウィンドウ / タブを閉じる | `Ctrl+W` | クエリ |

> **無効化されているキー**：`Ctrl+R` / `F5`（リロード）と `Ctrl+P` の印刷ダイアログは、誤操作を防ぐため無効化されています（`Ctrl+P` は QuickOpen に割り当て）。
